# Code of Conduct

## Our Standards

This is a proprietary codebase (see the Licensing section in `CONTRIBUTING.md`) maintained by a
small team plus occasional outside contributors. Regardless of company or affiliation, everyone
interacting in issues, pull requests, code review, or any other project space is expected to:

- Be respectful and constructive in feedback — critique the code, not the person.
- Accept code review comments in good faith; disagree by explaining reasoning, not by dismissing.
- Avoid harassment, insults, personal attacks, or discriminatory language or imagery.
- Respect differing viewpoints and experience levels.

## Unacceptable Behavior

- Harassment, trolling, or deliberately derailing discussion.
- Publishing others' private information without explicit permission.
- Any conduct that would reasonably be considered inappropriate in a professional setting.

## Enforcement

Instances of unacceptable behavior may be reported to the repository maintainers via a private
GitHub issue or direct message. Maintainers will review and respond to all reports and may edit,
remove, or reject comments, commits, code, issues, and other contributions that violate this
Code of Conduct, and may temporarily or permanently restrict access for behavior they deem
inappropriate, threatening, offensive, or harmful.

## Scope

This Code of Conduct applies within all project spaces (issues, pull requests, discussions,
commit messages) and in public spaces when an individual is representing the project.
